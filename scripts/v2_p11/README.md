# P11 local qualification tools

Run from the repository root in a user-authorized local Windows session. These tools create disposable repositories without publication remotes. They do not push or modify production project data. Runtime output belongs under `.factory/v2/p11/`; retained deliverable evidence is separately redacted and hashed.

1. Run `node scripts/v2_p11/validate.mjs memory` and `memory_resume`. Use one Cargo operation at a time. Set `CARGO_TARGET_DIR` to the approved local build cache; the runner records source fingerprints and preserves previous results.
2. Check the approved CLI once with `python scripts/v2_p11/preflight.py --cli <installed-codex.exe> --output .factory/v2/p11/preflight`. This makes one bounded real request using the existing authentication, model and supported MXC sandbox. Existing evidence is never overwritten. A quota refusal ends real-model experimentation; it is not permission to change accounts, endpoints or credentials.
3. Run all frontend checks, then build the embedded application using `node scripts/v2_p11/validate.mjs embedded`. Copy its executable to a uniquely named file under `.factory/v2/p11/run/`; do not rebuild a running Windows executable.
4. Set `ASF_P11_BINARY` to that copied executable. Run `node scripts/v2_p11/acceptance.mjs --ui-only` before the native experiment. This exercises production browser/API/storage controls without model requests; it is explicitly not real-agent evidence.
5. Run `node scripts/v2_p11/acceptance.mjs` once, using a new `ASF_P11_OUTPUT` directory if an earlier attempt already exists. It invokes genuine configured agents, interrupts only owned mission processes through P10, preserves partial work, resumes manually through the UI, and independently verifies the integration commit in a fresh checkout. No harness patch implements the task. Inspect any failure before starting another model experiment.
6. Measure bounded synthetic service performance using `cargo run -p factory-memory --example performance -j 1 -- <new-disposable-output-directory>`. This is local retrieval/storage throughput, not real coding-agent throughput. The fixture uses 100/1,000/10,000 records and three revisions per record; the entire generated database is disposable.
7. Complete `rust`, `parallel`, `frontend`, approved native IDE integration checks and retained browser regressions. Run expensive commands serially when host commit memory is constrained. A paging-file/host-resource failure is recorded distinctly from a failed product assertion.

The executed large-library measurement is also reproducible with `node scripts/v2_p11/acceptance.mjs --performance` and a fresh `ASF_P11_OUTPUT`. It uses four concurrent production API writers, three revisions per generated record, 100/1,000/10,000-record stages, real browser rendering and no model requests. The `performance` example is an alternative local service fixture, not the executed API measurement.

`replay.mjs` is a model-free continuation for the retained original native fixture. It completes browser audit/history/deletion/isolation steps without repeating agent execution. The original wrapper failure remains preserved. Its deletion step is intentionally not repeatable against an already-deleted record; create a fresh qualification fixture rather than fabricating historical state.

After the narrow extractor read-policy correction, copy the corrected embedded binary and run `postfix.mjs`. It uses the retained disposable Project B, temporarily narrows the actual selected Planner to one source file, proves another source is rejected before process launch, performs one real permitted extraction, restores the profile and performs one current-context conversation. It restores the project's extraction settings, preserves original execution snapshots, stops on provider quota refusal and never repeats the original coding mission. Select a fresh `ASF_P11_POSTFIX` output when preserving an earlier failed harness attempt.

The recorded final extractor succeeded. The supplementary query returned normal HTTP 202, but the original wrapper expected 200 and tore down its own server. This failure remains retained. `postfix.mjs --continue` performs **zero** model invocations: it checks the retained successful extractor and policy denial, verifies that restart marked the supplementary request interrupted without replay, validates the original process identity is absent, checks current project retrieval and inspects historical memory audit after deletion. It also supports an embedded frontend-only rebuild after proving production Rust source equivalence. Use a fresh `ASF_P11_POSTFIX` directory; do not resubmit the interrupted query to repair browser evidence.


The preflight records command arguments, CLI header, hashes, structured final response and selected refusal diagnostics. It does not retain full CLI reasoning output. Native acceptance retains session identities, snapshots, usage references and output hashes; historical ASF AgentSession logs remain subject to the existing project database retention policy.

Memory defaults remain enabled for retrieval, with automatic extraction disabled. The acceptance explicitly enables suggestion/review mode for its disposable project. P10 manual resume and the 180-second browser lease/60-second grace defaults are unchanged. No hosted search service, embedding model, credential setup or new policy authority is introduced.
