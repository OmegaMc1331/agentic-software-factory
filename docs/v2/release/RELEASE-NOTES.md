# ASF 2.0.0 release candidate

**Qualification candidate; ASF V2.0 remains NO-GO. Nothing has been published.**
The qualification checklist defines the exact-source evidence required for release. Implementation is not universal platform,
provider, accessibility or release certification.

V2 brings a project-scoped Rust runtime and a Dockview workspace with CodeMirror,
authorized filesystem editing, optional LSP/DAP tools, development terminals and
declarative extensions. Conversations create validated missions through the
existing Planner/Worker/Reviewer and integration pipeline. Parallel tasks use
separate worktrees, durable claims, repair/replanning and retained evidence.

Custom agent profiles provide versioned model/instruction configuration and safe
handoffs without transferring hidden inference state. Browser leases and durable
checkpoints support controlled suspension and manual resume. Project memory adds
categories, revisions, provenance, governance and bounded retrieval; it never
overrides security policy. Source Control exposes actual index/working-tree diffs,
hunk staging, commits, branches, reviews and authorized GitHub delivery previews.

The integrated workspace includes settings with distinct scopes, genuine durable
notifications, a command palette, keyboard navigation and recovery states. V1 and
its original `/` entry remain available; V2 is explicitly selected.

P14 prepares locked native builds, portable archives, per-file/asset integrity,
license inventory and a CycloneDX SBOM. CI is qualification-only with pinned
Actions, read-only permissions and independent architecture checks. No tag-triggered
publication job remains. Normal application shutdown is integrated with lifecycle
fencing and owned process cleanup; crash recovery remains a separate operation.

The security update narrows changes to audited dependency families: patched bundled
SQLite, MCP transport, Tokio and rustix. The complete candidate regression and
installation evidence must accompany any claim that these changes are qualified.
Known npm development-tool findings and license dispositions remain explicit.

Codex, Claude Code, OpenCode, Gemini, Qwen and custom adapter contracts do not imply
identical live support. Consult the provider campaign in V2-P14.md for actual
executables, authentication availability, model/test scope and refusals. A bounded
response test is not equivalent to a complete coding/cancellation qualification.

No remote PR was created for qualification. Live GitHub writes require a named,
authorized disposable repository. macOS signing/notarization, native platform and
exact-source remote CI gaps must remain visible until actual matching results exist.

The successor locks `url` at 2.5.9 to address RUSTSEC-2026-0592. The separate
picomatch build-tool advisory decision remains open. See [qualification](README.md).
