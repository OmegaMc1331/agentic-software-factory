# Agentic Software Factory

## Register

product

## Users

Individual developers who alternate manual editing and delegation to approved local agent CLIs, across several repositories. Sessions last hours and must preserve focus, source context and control over consequential operations.

## Product Purpose

A local Rust application with a browser workspace joining conversation, code and multi-agent missions. The approved [V2 product specification](docs/v2/product-spec.md) is normative. V1 stays operational while isolated V2 foundations are built.

## Brand Personality

Precise, calm, capable. Professional developer tooling with a distinct orchestrator-centered workflow. Familiar controls and compact technical information, without imitating another editor's identity.

## Anti-references

Marketing heroes, decorative cards/charts, simulated activity, AI orbs/robot avatars, neon gradients, glass surfaces, excessive rounding and perpetual decorative motion. Prototype data must be explicitly identified.

## Design Principles

1. Keep the current task central and technical detail available on demand.
2. Represent real authority, state and evidence faithfully.
3. Make manual work and delegated work feel part of one persistent workspace.
4. Preserve attention with consistent hierarchy, controls and keyboard behavior.
5. Keep local data and consequential operations under explicit user control.

## Accessibility & Inclusion

WCAG 2.2 AA where applicable, visible focus, keyboard navigation, meaningful status text, reduced motion, desktop zoom and accessible alternatives to graphs. P02 validates themes and interaction foundations; it does not qualify the complete V2 product.
