# Sample objectives

Enter an objective in **Agent Graph → + → Workflow**, then review the generated task
graph before selecting **Start**.

- Build a small HTTP server in Rust that returns JSON.
- Add a `/health` endpoint that responds with status JSON.
- Port the CLI's `--json` flag and add a unit test for the formatter.
- Optimize the database index for the tasks table and verify it with `EXPLAIN`.

Notes:

- Objectives are free-form; the configured Planner produces the task DAG.
- Keep objectives concrete and bounded. Include the deliverable, verification, and
  important constraints.
